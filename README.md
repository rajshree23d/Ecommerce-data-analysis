# Olist E-Commerce Analytics
### End-to-End Data Analytics Portfolio Project

## Overview
Complete analytics pipeline on Brazil's largest
e-commerce dataset — from raw data profiling
through advanced segmentation and statistical testing.

## What's Inside
| Analysis | Description |
|---|---|
| Data Profiling | Automated quality report across 9 CSVs |
| Data Cleaning | Null handling, outliers, feature engineering |
| EDA | Revenue trends, category analysis |
| RFM Analysis | Customer segmentation — 6 segments |
| Cohort Analysis | Retention heatmap by acquisition month |
| Outlier Detection | IQR and Z-score methodology |
| Statistical Testing | Hypothesis testing on delivery vs reviews |
| Seller Analysis | Performance tiering — Bronze to Platinum |

## Tools
Python, Pandas, NumPy, Matplotlib,
Seaborn, Scikit-learn, SciPy

## Key Findings
- Top 3 categories = 45% of total revenue
- On-time delivery = 92% of orders
- Late delivery reduces review score by 1.2 points
- Champions (8% of customers) = 35% of revenue
